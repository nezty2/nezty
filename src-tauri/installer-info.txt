nezty - honest, reversible game tweaks for Windows
https://github.com/nezty2/nezty

PRIVACY
nezty does not collect, store or send any personal data. No accounts, no analytics, no tracking.
nezty only connects to:
- GitHub Releases of nezty2/nezty, to check for updates (can be turned off in Settings > Updates)
- Steam, Epic and optionally SteamGridDB, to fetch game images (can be turned off in Settings > Covers)
- ping test servers, only when you use the Network page or the dashboard ping
- Cloudflare's speed test (speed.cloudflare.com), only when you start the bufferbloat test yourself

CHANGES TO WINDOWS
Every tweak is explained before you apply it, is logged with its old value and can be undone with "Undo all".
Before the first change nezty creates a Windows restore point. Uninstall nezty through Windows Settings > Apps.

PRIVACY (NEDERLANDS)
nezty verzamelt, bewaart en verstuurt geen persoonlijke gegevens. Geen accounts, geen analyse, geen tracking.
nezty maakt alleen verbinding met GitHub (updates, uit te zetten in Instellingen), Steam, Epic en eventueel
SteamGridDB (game-afbeeldingen, uit te zetten in Instellingen), testservers voor ping (alleen als je die test gebruikt)
en de snelheidstest van Cloudflare (alleen als je zelf de bufferbloat-test start).
